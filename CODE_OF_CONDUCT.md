# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and critique work rather than people.
Harassment, discrimination and personal attacks are not tolerated in issues,
pull requests, discussions or any other project space.

## Reporting

To report behaviour that breaks this code, contact the maintainer privately
through the contact details on the
[@mehShekari GitHub profile](https://github.com/mehShekari). Reports are handled
confidentially.

The maintainer may remove, edit or reject contributions, and temporarily or
permanently ban contributors, for behaviour they judge inappropriate, following
the Contributor Covenant's enforcement guidelines.
